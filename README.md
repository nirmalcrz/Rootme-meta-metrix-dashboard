# Rootme Business Overview

A static dashboard for Rootme: Meta ads spend and leads, Metrix leads by course and status, and team performance.

- `index.html` – the dashboard page (no build step)
- `meta.js` – Meta ads data per month (refreshed daily)
- `leads.js` – Metrix lead counts by day, course, status and team (updated when a new Metrix export is added)

The files contain counts and spend only. Lead names and phone numbers are not stored here.
